# ☕ OOPs with Java

A comprehensive set of Java programs demonstrating key concepts of **Object-Oriented Programming (OOP)**. This repository is perfect for beginners learning Java and the principles of OOP in action.

## 📘 Overview

This repository covers:

- 🧱 Classes & Objects
- 🔐 Encapsulation
- 🧬 Inheritance
- 🎭 Polymorphism (Compile-time & Runtime)
- 🧩 Abstraction
- 🔁 Constructors & Method Overloading
- 🔄 Interface vs Abstract Classes
- 📦 Packages and Access Modifiers

Each topic is implemented through small, focused Java programs with clear structure and comments.

## 🧠 Learning Goals

- Understand the **four pillars** of OOP: Abstraction, Encapsulation, Inheritance, and Polymorphism.
- Practice writing reusable and modular Java code.
- Grasp how Java implements OOP principles practically.
- Gain confidence in using Java syntax, classes, and object hierarchies.
