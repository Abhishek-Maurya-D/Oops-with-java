# 🚀 Oops-with-Java

A beginner-friendly collection of **Object-Oriented Programming (OOP)** examples written in **Java** to help learners understand core concepts such as classes, objects, inheritance, polymorphism, abstraction, and encapsulation.

(OOP principles make code modular, reusable, and easier to maintain.) :contentReference[oaicite:0]{index=0}

---

## 📌 Repository Summary

This repository includes:

✅ Java programs demonstrating OOP concepts  
✅ Practical examples with real code  
✅ Logical directory structure  
✅ Helps beginners practice and understand OOP

Each folder (or file) focuses on one concept so you can focus on learning step by step.

## 📥 Getting Started

To begin using or trying out the examples:

### 🧾 Prerequisites

You should have:

✔ Java Development Kit (JDK) installed  
✔ A code editor or IDE like **VS Code**, **IntelliJ IDEA**, or **Eclipse**

---

## 🛠️ How to Clone & Run

1. **Clone the repository**

```bash
git clone https://github.com/Abhishek-Maurya-D/Oops-with-java.git
````

2. **Open the project**

   * Use a Java IDE (recommended)
   * Or navigate to the folder in terminal

3. **Compile & run a Java file**

```bash
javac Example.java
java Example
```

> Replace `Example.java` with the actual file you want to run.

---

## 💡 Example: Running Encapsulation Example

Assuming there’s a file `EncapsulationDemo.java`:

```bash
javac EncapsulationDemo.java
java EncapsulationDemo
```

You should see output that demonstrates how private fields are accessed via getters/setters (encapsulation in action).
